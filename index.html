약재 이름을 누르면 업체별 모든 상품이 펼쳐집니다. 빨간 최저 칸이 그 약재의 최저 단가입니다. 14일 넘게 갱신되지 않은 가격은 노란색입니다.

이번 주문 목록

약재 이름과 근 수를 한 줄에 하나씩, 또는 쉼표로 이어서 한꺼번에 적으세요. 근 수는 비워 두고 나중에 표에서 넣어도 됩니다. 원산지·규격은 넣은 뒤 표에서 고를 수 있습니다. 목록은 모든 직원에게 공유됩니다.

빨간 금액이 그 약재의 최저가, 네모 테두리가 지금 담긴 업체입니다. 다른 업체 칸을 누르면 그쪽으로 바뀝니다. 비교와 자동 선택은 g당 가격(원/kg) 기준입니다. 칸 아래 금액은 포장 단위로 필요량을 채웠을 때 실제로 내는 돈이고, (+g)은 필요량보다 더 받는 양입니다.

배송비 포함 총액

쇼핑몰 장바구니에 담기

위 업체별 주문이 맞으면 확정하세요. 그다음 쇼핑몰(바이퓨어·메디마켓)에 로그인해서 즐겨찾기 약재가격보내기 → 주문 목록 장바구니에 담기를 누르면 개수대로 담깁니다. 메디마켓은 상품을 하나씩 검색해서 담으니 품목당 몇 초씩 걸립니다. 결제는 직접 확인하고 하세요. 쿠팡은 직접 담아야 합니다.

업체 배송비·최소 주문금액

배송비, 무료배송 기준, 최소 주문금액(예: 바이퓨어 100,000원)을 넣으면 주문 계산에 반영됩니다.

글자색 의미

약재 목록 사진의 글자색을 그대로 옮겼습니다. 색마다 뜻을 적어 두면 비교표에 같이 보입니다.

약재 메모

다른 이름(예: 율무 → 의이인)을 적으면 같은 약재로 묶여 비교됩니다. 메모는 비교표와 주문 목록에 노란 글씨로 보입니다.

가격 보내기 버튼이란

윈도우 PC와 맥(Mac)의 크롬·엣지·사파리 즐겨찾기 막대에 저장해 두는 버튼입니다. 쇼핑몰에 로그인한 화면에서 이 즐겨찾기를 누르면, 화면의 약재 가격을 읽어 이 비교 사이트로 보냅니다. 따로 설치할 프로그램은 없습니다. 주문하는 PC마다 한 번씩 저장해 두세요.

버튼 저장하기

  1. 즐겨찾기 막대를 켭니다.
    윈도우 크롬·엣지: Ctrl+Shift+B · 맥 크롬·엣지: ⌘+Shift+B · 맥 사파리: 메뉴 보기 → 즐겨찾기 막대 보기
  2. 아래 초록 버튼을 마우스로 끌어 즐겨찾기 막대에 놓습니다.
  3. 쇼핑몰에 로그인한 뒤 즐겨찾기 막대의 약재가격보내기를 누릅니다.

약재가격보내기

끌어 놓기가 안 될 때

  1. 아래 버튼 주소 복사를 누릅니다.
  2. 크롬·엣지(윈도우·맥): 즐겨찾기 막대에서 오른쪽 클릭 → 페이지 추가(엣지는 즐겨찾기 추가) → 이름 약재가격보내기, URL에 붙여넣기 → 저장
  3. 맥 사파리: 아무 페이지에서 ⌘+D로 즐겨찾기 막대에 추가 → 막대의 그 즐겨찾기를 오른쪽 클릭 → 주소 편집 → 붙여넣기, 이름도 약재가격보내기로 변경
